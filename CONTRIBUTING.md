# Contribution Guidelines for NovaOS

Thank you for your interest in contributing to NovaOS! This document provides the guidelines for contributing to our project. Please follow these instructions to ensure a smooth contribution process.

## Getting Started
1. **Fork the Repository**: Start by forking the repository to your GitHub account. 
2. **Clone Your Fork**: Clone your forked repository to your local machine using:
   
   ```bash
   git clone https://github.com/<your-username>/NovaOS.git
   ```
3. **Create a Branch**: Before making any changes, create a new branch for your work:
   
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Coding Standards
- Use **C** for coding. Follow the GNU coding standards for C programming.
- Write meaningful commit messages and document your code clearly.

## Testing
- Ensure that your code passes the existing tests in the repository.
- Write new tests for any new features or bug fixes you implement.

## Submitting Changes  
1. **Commit Your Changes**: Once your features are complete, commit your changes:
   
   ```bash
   git commit -m "Add new feature..."
   ```
2. **Push to Your Fork**: Push your changes to your fork:
   
   ```bash
   git push origin feature/your-feature-name
   ```
3. **Create a Pull Request**: Go to the original repository on GitHub and create a new pull request from your branch.

## Code Review  
- Once you submit a pull request, other contributors will review your code. Be open to feedback and willing to make adjustments as necessary.

## Additional Information  
- For large changes, it's recommended to discuss them with maintainers before writing code.
- Join our conversations on the [project's forum](#) or chat with us in our Slack channel!

Thank you for helping make NovaOS great!  
Happy coding!
